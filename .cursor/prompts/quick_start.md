# Quick Start

1. `/design-review-start`
2. Выбери режим `1-4`
3. Дизайн-система:
   - если в `DESIGN REVIEW REPORT/` уже лежит `design-system-*.md` от прошлой сессии — агент покажет самый свежий с его кодовым именем (например, *Jupiter*) и спросит: `1` использовать его, `2` приложить новую, `3` без ДС
   - если кэша нет — приложи картинку style-guide / ссылку на Figma library / пропусти (`Пропустить` или `-`)
4. Если приложил новую — агент пришлёт извлечённый чек-лист правил, ты его подтверждаешь / правишь, агент даст ей случайное планетарное имя (Mercury…Makemake) и сохранит как `design-system-<planet>_DD-MM-YYYY-HH-MM.md` для будущих чатов
5. Передай входные данные
6. Подтверди тему экрана (агент предложит её одной строкой)
7. Получи отчёт с осмысленными именами файлов и блоком «Соответствие дизайн-системе»
